# **App Name**: VoltVision

## Core Features:

- Real-time Dashboard: Real-time dashboard displaying voltage and current readings from configured sources.
- Historical Data Visualization: Historical data visualization of voltage, current, and calculated battery level using interactive charts.
- API Data Ingestion: API endpoint to ingest minified JSON data from an Arduino microcontroller.
- Sensor Data Storage: Storage of voltage and current readings in a PostgreSQL database, optimized for time-series data.
- Sensor Data Storage: Storage of voltage and current readings in a SQLite database, optimized for time-series data.
- Battery Health Optimization: AI-powered recommendations tool that analyze historical battery data to suggest optimal usage patterns for extending battery life.

## Style Guidelines:

- Background color: Very Dark Gray (#121212), mimicking Spotify's dark mode base.
- Primary color: Muted Pink (#F06292) for a modern and technical feel, evoking electricity and data visualization.
- Secondary Color: Dark Gray (#282828) for elements needing further visual separation.
- Accent color: Light Pink (#F8BBD0), an analogous color to the primary, will add contrast and highlight interactive elements and real-time data points.
- Headline font: 'Space Grotesk' sans-serif font for headings. Body Font: 'Inter', a clean, readable grotesque-style sans-serif, ideal for longer passages.
- Code font: 'Source Code Pro' for displaying configuration snippets.
- Use a set of minimalist icons representing voltage, current, battery status, and data sources, adhering to a consistent line thickness and style.
- Dashboard layout to feature a clear hierarchy with real-time data prioritized at the top, followed by historical charts and sensor source information.
